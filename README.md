# LeadPilot MVP

A zero-API, browser-based lead qualification workspace. Runs as a static website and requires no paid credits.

## Features
- Define a target niche, geography, offer, and keyword signals.
- Paste prospects or import a CSV.
- Score and rank prospects with transparent keyword heuristics.
- Export a scored CSV with reasons and next steps.
- No account, backend, or API key required.

## Run locally
Open `index.html` in a modern browser.

## Enable GitHub Pages
In the repository, open **Settings → Pages**, select **Deploy from a branch**, choose **main** and **/(root)**, then save. Once published, the site URL appears in that section.

## CSV format
Recommended header:
`company,website,industry,location,notes,contact,email`

## Limitations
This MVP does not scrape websites, verify contacts, send outreach, or use an AI model. Scores are heuristic estimates, not verified intent or a promise of conversion. Use permitted data and comply with applicable privacy, platform, and anti-spam rules.
