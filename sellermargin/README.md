# SellerMargin

A free, mobile-friendly product contribution and break-even calculator for online sellers. Static HTML/CSS/JavaScript; no backend, account, or paid API required.

## Run
Open `index.html` in a browser. It also works as a subfolder on GitHub Pages.

## Calculations
- Contribution per unit = selling price − product cost − shipping/packaging − marketplace fees − ads per unit − returns allowance − other costs.
- Contribution margin = contribution ÷ selling price × 100.
- Break-even selling price = entered per-unit costs.
- Monthly contribution estimate = contribution × units sold.

## Limitations
This MVP uses user-entered assumptions. It does not automatically retrieve marketplace fee schedules and does not automatically account for taxes, fixed overhead, refunds timing, or every marketplace-specific charge. Validate all inputs before making business decisions.

## Before selling
